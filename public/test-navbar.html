🎨 Industrial Notification Navbar

Lifeline Charity Platform - Modern & Professional Notification System

Features

  • Industrial dark theme with red accent color
  • Real-time notification polling (5-second intervals)
  • Unread notification badge counter
  • Dropdown notification panel with notifications list
  • Status indicators for different notification types
  • Mark as read functionality (single & bulk)
  • Responsive design for mobile devices
  • Smooth animations and hover effects
  • Automatic dark mode support
🔔 Click the bell icon in the navbar to see notifications! Test it by:
  1. Submitting a case as patient
  2. Logging in as Lifeline team member
  3. Seeing the notification in the bell dropdown

Notification Types

Case Submitted: Patient submits a new case → Lifeline team notified with NEW badge

Case Approved: Lifeline team approves case → Patient notified with APPROVED badge ✅

Case Rejected: Lifeline team rejects case → Patient notified with REJECTED badge

Case Updated: Case information updated → Related parties notified

Donation Received: Donation comes in → Patient notified with DONATION badge

Integration

The navbar has been integrated into:

  • doctor-dashboard.html - Lifeline team dashboard
  • patient-dashboard.html - Patient case dashboard
